# Decor AI Monorepo (Backend + Mobile)

The root Next.js web app has been removed.

This repo now contains:

- `backend/` — Express + TypeScript API
- `mobile/` — Expo React Native app

## Run from repo root

```bash
npm run dev:backend
npm run dev:mobile
```

Optional mobile targets:

```bash
npm run android
npm run ios
npm run web
```

## Build backend

```bash
npm run build:backend
```
